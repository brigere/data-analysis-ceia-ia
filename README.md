# Análisis de Datos - CEIA

Este repositorio contiene actividades individuales correspondientes a la materia "Análisis de Datos" de la Carrera de Especialización en Inteligencia Artificial (CEIA) de la UBA.

## Requisitos

- Python 3.12+
- [uv](https://docs.astral.sh/uv/) como gestor de paquetes

## Cómo ejecutar

1. Instalar las dependencias:

   ```bash
   uv sync
   ```

2. Ejecutar un script:

   ```bash
   uv run python <script.py>
   ```

3. Levantar Jupyter Lab para trabajar con los notebooks:

   ```bash
   uv run jupyter lab
   ```

### Agregar una dependencia

```bash
uv add <paquete>
```
